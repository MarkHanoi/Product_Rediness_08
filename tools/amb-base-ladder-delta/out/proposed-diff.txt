§EXTRAPOLATION-DISCONTINUITY. `BCN_STOREY_MODULE_M = 3.05` and `BCN_GROUND_FLOOR_DATUM_M = 5.5`
are derived, VERBATIM in the module comment, from the BASE table:
    «module = (23.8 − 8.55)/(6 − 1) = 3.05 m and base = 8.55 − 3.05 = 5.5 m»
SIG-2 replaced the table and did NOT replace the constants. Barcelona's applied ladder has a slope
of (25.75 − 9.00)/5 = 3.35 m/storey. So the function is internally inconsistent:

    PB+6  →  25.75 m   (table, Barcelona's slope)
    PB+7  →  5.5 + 3.05×7 = 26.85 m   (extrapolated, the BASE ladder's slope)
    ⇒ one whole extra storey buys 1.10 m.

  measured in this run (21.6 %) land in this branch. Because BOTH arms extrapolate on the SAME
  constants, every one of those parcels recorded a delta of EXACTLY ZERO.
  ⇒ ⭐ THE MEASURED HEIGHT DELTA IN THIS RUN IS A LOWER BOUND. The masked parcels are not correct;
    they are served by a slope belonging to neither governing table, in Barcelona too.

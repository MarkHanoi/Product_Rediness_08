# ISO GAP REGISTER — PRYZM

**Status**: DRAFT · **Created**: 2026-08-09 · Companion to [ISO-READINESS-MATRIX](./ISO-READINESS-MATRIX.md) and [PRYZM-ENVELOPE-ASSURANCE-SPEC](./PRYZM-ENVELOPE-ASSURANCE-SPEC.md).

## How to read this register

- **CLASS** — the founder-mandated separation. Every row is exactly one of:
  **`compliance control`** (ISO-driven reliability of the system) ·
  **`envelope gate`** (validity of an individual envelope) ·
  **`quality improvement`** ·
  **`administrative evidence`** (a record an auditor needs; no product effect).
  ⛔ **A `compliance control` or `administrative evidence` row MUST NOT become an envelope refusal reason.**
- **EFFORT** — one competent engineer, excluding review and deploy. `research` means it is not
  engineering time at all.
- **PRIORITY** — set by *expected additional legally defensible envelopes ÷ (implementation + research
  cost)*, then by risk. **Not** by ease.
- Owners are **proposed**. Assignment is a founder act.
- ⚠ This register does **not** restate the L-NN Issue Log. Where a gap is already an L-row, the row is
  cited and only the ISO framing is added.

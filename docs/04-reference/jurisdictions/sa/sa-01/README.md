# Riyadh Region (`sa-01`) — what is true now

**Level:** region (ISO 3166-2 **SA-01**, *منطقة الرياض* Riyadh Region) · **Last updated:** 2026-07-23 ·
**Status:** container level — no regional zoning instrument.

## 1 — What governs here
Saudi residential zoning is **national** (the 2024 MOMRAH decision — see [`../README.md`](../README.md)),
with the VERTICAL extent deferred to the **municipal** plan and to **development-authority** regs. There
is **no region-level (SA-01) zoning instrument** in between. Per `JURISDICTION-PLAYBOOK.md` §1 a region
layer is not forced where the law is not regional; `sa-01/` exists here only as the ISO 3166-2 path
segment carrying the demo municipality, **Riyadh** ([`ruh-riyadh/`](ruh-riyadh/README.md), UN/LOCODE RUH).

## 2 — Pack status
No region-level pack. The pack is at the municipality level (`sa-ruh-riyadh`). See `ruh-riyadh/`.
